# Maria Habib Portfolio — GitHub Pages

Create a public repository named `maria-habib17.github.io` on your GitHub account. Upload the **extracted files** (not the ZIP) to the repository root, commit to `main`, then open Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save. Your site will be at https://maria-habib17.github.io/ once published.
